# Design and Analysis of Algorithms - Lab 07

This folder contains the C implementations and explanations for DAA Lab 07.

## Questions Overview

| Question | Description |
| --- | --- |
| Q01 | Invert the coin-triangle to find the minimum number of coin slides. |
| Q02 | Solve the super egg dropping problem using dynamic programming. |
| Q03 | Compute the minimum moves for Reve's puzzle using 4 pegs. |
| Q04 | Find the minimum toggles to turn off all security switches using BFS. |
| Q05 | Explore whether a guaranteed strategy exists for a moving target. |
| Q06 | Find the year with the maximum number of people alive using event sorting. |
| Q07 | Solve Matrix Chain Multiplication using dynamic programming. |
